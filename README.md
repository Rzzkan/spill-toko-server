# Spill Toko — Server

Proyek pribadi: layanan server (Laravel) pendamping extension browser Spill Toko.

## Gambaran umum
- Akun pengguna dan login.
- Paket langganan dan pembayaran.
- Panel admin untuk pengaturan dan pemantauan.
- Layanan analisis berbasis AI untuk extension.

## Status
Dalam pengembangan, hanya untuk penggunaan internal pemilik.

## Hak cipta
Hak cipta dilindungi. Seluruh isi repositori ini bersifat privat dan tidak boleh disalin, dipakai,
dimodifikasi, atau didistribusikan oleh pihak lain tanpa izin tertulis dari pemilik.
